Entry for the make.fun bounty [Sum up 25 November's world news in one image](https://make.fun/bounty/news-image-20261125).

A Python program (standard library only, no network) that draws one
1024x1024 PNG of the day's world news: a dotted world map with the
places where it happened, four top stories, and fourteen briefs.
Every story carries its own small drawn picture.

## Run

```sh
python3 main.py
```

Writes `/output/entry.png` (and `output/entry.png` next to the
script). The output is deterministic: two runs produce identical
bytes.
